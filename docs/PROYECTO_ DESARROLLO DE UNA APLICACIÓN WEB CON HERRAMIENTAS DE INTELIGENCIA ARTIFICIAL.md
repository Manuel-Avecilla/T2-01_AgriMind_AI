# **PROYECTO: DESARROLLO DE UNA APLICACIÓN WEB CON HERRAMIENTAS DE INTELIGENCIA ARTIFICIAL**

## **1\. Objetivo del proyecto**

El objetivo de este proyecto es desarrollar una aplicación web utilizando un entorno de desarrollo asistido por inteligencia artificial, incorporando diferentes herramientas y extensiones que permitan mejorar el proceso de diseño, programación, depuración y desarrollo del software.

Para ello, tendréis que investigar, seleccionar, instalar, configurar y utilizar diferentes **Skills, MCPs, Providers y Plugins**, comprobando de qué manera contribuyen a mejorar vuestro trabajo como desarrolladores.

No se trata simplemente de utilizar herramientas de IA para generar código, sino de aprender a ampliar las capacidades de vuestro entorno de desarrollo mediante la integración de nuevas funcionalidades.

## **2\. Desarrollo de la aplicación web**

Cada alumno o grupo deberá desarrollar una aplicación web basada en la empresa con ánimo de lucro que se empezó en tareas anteriores.

La aplicación deberá contar con una interfaz web cuidada, funcionalidades útiles y una estructura coherente. No será suficiente con presentar una página estática o una simple demostración visual como fue el caso de la tarea anterior.

## **3\. Investigación e integración de herramientas**

Durante el desarrollo tendréis que investigar e incorporar, como mínimo, los siguientes elementos:

### **A. Skills (mínimo 2\)**

Deberéis investigar y utilizar al menos **2 Skills diferentes**.

Para cada Skill tendréis que:

* Explicar qué es y cuál es su finalidad.  
* Identificar qué capacidades incorpora al entorno de desarrollo.  
* Explicar dónde se puede conseguir.  
* Mostrar cómo se instala o configura.  
* Justificar por qué la habéis elegido.  
* Explicar y demostrar cómo ha mejorado vuestro desarrollo.

Las Skills deben tener una utilidad real dentro del proyecto. No se valorará positivamente instalar herramientas que después no se utilicen.

### **B. MCPs (mínimo 2\)**

Deberéis investigar e integrar al menos **2 servidores MCP (Model Context Protocol)** diferentes.

Para cada MCP tendréis que:

* Explicar qué es y qué servicio proporciona.  
* Identificar qué herramientas o recursos pone a disposición del modelo de IA.  
* Explicar dónde se consigue.  
* Mostrar cómo se configura y conecta con vuestro entorno.  
* Indicar qué permisos o credenciales necesita.  
* Demostrar cómo lo habéis utilizado durante el desarrollo.  
* Explicar qué ventajas ha aportado al proyecto.

Se valorará especialmente que los MCPs permitan interactuar con servicios externos, bases de datos, sistemas de archivos, herramientas de diseño u otros recursos.

### **C. Providers (mínimo 1\)**

Deberéis investigar, configurar y utilizar al menos **1 Provider diferente** en vuestro entorno de desarrollo.

Para ello tendréis que:

* Explicar qué es un Provider y qué función desempeña.  
* Identificar el proveedor elegido y los modelos de IA que ofrece.  
* Explicar cómo se configura en vuestro entorno.  
* Indicar qué credenciales o API Key necesita, si corresponde.  
* Justificar por qué habéis seleccionado ese Provider.  
* Explicar qué ventajas ofrece frente a otras alternativas.  
* Demostrar cómo lo habéis utilizado en el desarrollo de la aplicación.

### **D. Plugins (mínimo 2\)**

Deberéis investigar e integrar al menos **2 Plugins nuevos** en vuestro entorno de desarrollo.

Para cada Plugin tendréis que:

* Explicar qué funcionalidad incorpora.  
* Identificar qué problema resuelve.  
* Mostrar cómo se instala o configura.  
* Explicar cómo se utiliza.  
* Justificar su elección.  
* Demostrar cómo ha contribuido a mejorar el desarrollo.

Los Plugins deberán aportar funcionalidades diferentes y útiles. Se valorará que amplíen las posibilidades del entorno de desarrollo y no se limiten a duplicar herramientas que ya utilizáis.

**Importante:** Los elementos seleccionados deberán ser nuevos para vosotros y no limitarse a repetir configuraciones o herramientas utilizadas habitualmente en prácticas anteriores.

## **4\. Presentación del proyecto**

Junto con la aplicación web, tendréis que realizar una presentación en la que expliquéis el proceso de desarrollo y las herramientas utilizadas.

La presentación deberá incluir obligatoriamente los siguientes apartados:

1. **Descripción de la aplicación**  
   * Nombre del proyecto.  
   * Problema o necesidad que resuelve.  
   * Público al que va dirigida.  
   * Funcionalidades principales.  
   * Tecnologías utilizadas.  
2. **Skills utilizadas**  
   * Identificación de las Skills.  
   * Funcionalidad de cada una.  
   * Instalación y configuración.  
   * Ejemplos de utilización.  
   * Mejoras aportadas al desarrollo.  
3. **MCPs utilizados**  
   * Identificación de los servidores MCP.  
   * Servicios y herramientas que proporcionan.  
   * Instalación y configuración.  
   * Ejemplos de utilización.  
   * Mejoras aportadas al desarrollo.  
4. **Provider utilizado**  
   * Identificación del Provider.  
   * Modelos disponibles y modelo seleccionado.  
   * Configuración y conexión.  
   * Motivos de la elección.  
   * Ventajas obtenidas durante el desarrollo.  
5. **Plugins utilizados**  
   * Identificación de los Plugins.  
   * Funcionalidades que incorporan.  
   * Instalación y configuración.  
   * Ejemplos de utilización.  
   * Mejoras aportadas al desarrollo.  
6. **Conclusiones**  
   * Dificultades encontradas.  
   * Herramientas que han resultado más útiles.  
   * Comparación entre el desarrollo sin estas herramientas y el desarrollo utilizándolas.  
   * Qué cambiaríais o mejoraríais en una futura versión.

La presentación deberá incluir capturas de pantalla, ejemplos de configuración y demostraciones reales de las herramientas utilizadas.

No será suficiente con copiar información de Internet: deberéis demostrar que comprendéis las herramientas y que sabéis utilizarlas.

## **5\. Originalidad y criterios de valoración**

La originalidad será uno de los aspectos más importantes de este proyecto.

Se valorará especialmente:

* Que la aplicación presente una idea propia y diferenciadora.  
* Que aporte soluciones creativas a problemas reales.  
* Que las funcionalidades no sean una simple copia de aplicaciones conocidas.  
* Que las Skills, MCPs, Providers y Plugins se seleccionen de forma razonada.  
* Que se realice una integración efectiva de las herramientas.  
* Que se demuestre iniciativa y capacidad de investigación.

## **6\. Entregables**

Al finalizar el proyecto se deberán entregar:

1. **Código Github:** Código fuente de la aplicación.  
2. **Aplicación web:** Enlace a la página web.  
3. **Presentación:** documento o presentación digital con todos los apartados indicados.

## **7\. Condiciones importantes**

* Se deberán utilizar al menos 2 Skills, 2 MCPs, 1 Provider y 2 Plugins.  
* Todos los elementos deberán estar realmente configurados y utilizados.  
* No se aceptará una herramienta instalada que no se haya utilizado.  
* Las credenciales, contraseñas y API Keys no deberán aparecer en la presentación ni en el código fuente público.  
* El alumnado deberá ser capaz de explicar el funcionamiento de su aplicación y las herramientas incorporadas.  
* Se valorará la capacidad de investigación, autonomía, creatividad y resolución de problemas.
